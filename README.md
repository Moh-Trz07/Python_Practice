# 🐍 Python Practice Projects

A collection of beginner-to-intermediate Python projects.

---

## 📂 Projects

### 1. Basic ChatBot 🤖
A simple rule-based chatbot.
- Uses a list of 9 fixed responses.
- Checks for keywords in user input.
- Case-insensitive matching.
- No AI, no memory—just simple logic.
- Continuous loop until user types "exit".

---

### 2. Move JPG Files 📁➡️📁
Automates moving JPG files from one folder to another.
- Uses `os` module to interact with the operating system.
- Uses `shutil` module to handle file operations.
- Lists all files in the source folder.
- Uses `if-else` to check if source/destination folders exist.
- Uses `try-except` for error handling during file moves.

---

## 🛠️ Technologies Used
- Python 3
- `os` module
- `shutil` module
